# Ansh Varshney - Portfolio

A Visual Studio Code themed developer portfolio website built with Next.js and CSS Modules.

## Overview

Portfolio of **Ansh Varshney** — Data Science student at IIT Madras, Summer Intern at IIT Ropar, and Open Source Contributor at ECSoC.

## Features Roadmap

- [x] Themes and customizations
  - [x] Night Owl (default)
  - [x] GitHub Dark
  - [x] Dracula
  - [x] Ayu
  - [x] Nord
- [x] Interactive custom terminal
- [x] VSCode-styled interface & command palette

## Environment Variables

To configure GitHub integration, create an `.env.local` file inside the project directory:

```env
NEXT_PUBLIC_GITHUB_USERNAME=anshvarshney1502
```

## Running Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or default port) with your browser to see the result.
